# 文档批量处理工具 · 使用说明

> 单文件程序，复制到目标电脑双击即可，**不需要安装 Python**。

---

## 目标电脑要求

| 项目 | 要求 |
|---|---|
| 操作系统 | **Windows 10 / Windows 11**（64 位） |
| 办公软件 | **WPS Office 或 Microsoft Word，装其一即可**（程序靠它读写文档） |
| 其他 | 无。不用装 Python、不用装运行库 |

> 为什么必须装办公软件：`.doc` 是二进制格式，Python 库改不了，必须借 WPS / Word 自己的引擎来读写。这是这个工具能保证"格式不走样"的原因。
>
> **程序启动时会自动检测**，优先用 WPS Office，没有 WPS 再用微软 Word，控制台和界面日志都会打出来。两个都没装的话会弹窗提示「需要安装 WPS 或者 Microsoft Office，任务无法开始」，同时转换 / 查找 / 替换按钮会保持灰色不可点。
>
> 如果电脑同时装了 WPS 和 Word：WPS 安装时会把 `Word.Application` 这个接口接管过去，所以本工具统一优先走 `KWPS.Application`（WPS 官方接口）；只有确实没有 WPS 时才走微软 Word。

---

## 怎么用

**1. 复制**

把 `文档批量处理工具.exe` 这一个文件复制到目标电脑任意位置（桌面、D 盘都行）。

**2. 双击运行**

会弹出一个黑色命令行窗口，显示：

```
========================================================
  文档批量处理工具
  地址: http://127.0.0.1:8770
  日志目录: C:\...\logs
  关闭这个窗口即可停止服务
========================================================
```

浏览器会自动打开操作界面。

**首次启动会慢 3~8 秒**（单文件程序要先自解压），之后就快了，属正常现象。

**3. 操作**

界面左边三步走：选目录 → 预处理（转换/清理）→ 查找替换；右边是实时日志。

详细功能说明见同一目录下的 `README.md`。

**4. 关闭**

直接关掉那个黑色窗口就行。

## 常见问题

**任务卡在某个文件不动了**

这是最需要知道的一条。绝大多数情况是**办公软件弹了个对话框**：文件损坏是否修复、是否更新链接、受保护的视图、编码选择、文件正在使用……

对话框一出现，程序对办公软件的调用就永远不返回，整个任务停在那儿，连取消按钮都点不动。程序无法从代码里强行打断它。

**处理办法（按顺序试）**：

1. **先看界面上有没有 Word 弹窗**——有就点「否 / 取消」把它关掉，任务会立刻接着跑。
2. **看不到弹窗就点右上角「中断并清理进程」**——点了会先弹确认框，点「确认中断」才动手：
   它会结束后台跑着的 Word / Excel 进程、删掉目录里的 `~$` 锁文件，卡住的任务马上结束；
   已经处理好的文件不受影响，卡住的那份记为「打不开」。
   你自己开着编辑的 Word 文档默认不会被关掉（需要时程序会再问你一次）。

新版做了三层防护：

1. **尽量不弹**：打开文档时禁用宏、关闭链接更新、不弹编码选择、不自动修复、关闭拼写检查
2. **卡住会喊**：某个文件超过 90 秒没动静，底部出现红色提示条，日志里也有一条黄色警告，写明卡在哪个文件
3. **一键解除**：顶部「中断并清理进程」按钮，任务执行期间也始终可点

阈值可以用环境变量 `TOOLKIT_FILE_TIMEOUT` 调。

> ⚠️ **中断的代价**：强杀 Word 时它如果正在保存某一份文档，**那一份可能写残**（实测遇到过一个，Word 连"打开并修复"都救不回来）。
> 替换任务有备份可以从 `_备份_时间戳` 恢复；转换任务源文件还在，重新转一次就行。**中断后看一眼日志里最后那个文件**。

**浏览器没自动打开**

手动在地址栏输入窗口里显示的地址（通常是 `http://127.0.0.1:8770`）。
如果 8770 被别的程序占了，程序会自动往后找空闲端口，**以窗口里显示的地址为准**。

**双击后一闪而过 / 提示缺少 DLL**

极少数精简版 Windows 缺少 VC++ 运行库。装一下微软官方的
**Visual C++ 2015-2022 Redistributable (x64)** 即可。

**杀毒软件报警 / 文件被隔离**

单文件打包程序（PyInstaller）被误报是行业普遍现象。处理方式：
在杀软里把这个 exe 加入信任/白名单。如果公司电脑有管控，需要找 IT 放行。

**日志在哪**

exe 同目录下的 `logs` 文件夹，**每次启动程序生成一个独立文件**（如 `run_20261113_095748.log`）。

文件开头是这次运行的启动记录（启动时间、程序目录、**引擎检测结果**），后面依次追加各个任务的日志。所以哪怕一次任务都没跑，点「下载」也能拿到带引擎检测的完整记录。

只保留最近 30 次运行的日志，更早的自动清理。

如果 exe 放在只读位置（比如 Program Files），会自动改存到 `%USERPROFILE%\DocToolkit\logs`，命令行窗口里会显示实际路径。

**能不能放 U 盘直接用**

可以。exe 是绿色单文件，不写注册表、不装服务，U 盘里双击就能跑。

## 换端口 / 特殊场景

如果你需要固定端口，可以先设环境变量再运行：

```bat
set TOOLKIT_PORT=9000
文档批量处理工具.exe
```

不设的话默认从 8770 开始自动找空闲端口。
